# Project Assets

Each project has its own folder. Add screenshots, demo stills, or short exported images there.

After adding an image, update the matching project in `src/data/portfolio.ts`:

```ts
image: "assets/projects/qnow/qnow-dashboard.jpg"
```

Recommended image types: `.jpg`, `.png`, or `.webp`.
Recommended size: at least 1200px wide for featured projects.
