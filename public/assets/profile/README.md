# Profile Assets

Put your profile/headshot photo here.

Recommended filename:

```text
mohamed-aziz-guenni-profile.jpg
```

Then update `profile.photo` in `src/data/portfolio.ts`:

```ts
photo: "assets/profile/mohamed-aziz-guenni-profile.jpg"
```

Use a clear, professional image with good lighting. A square or vertical crop works best.
