# Certificate Assets

Put actual certificate images or PDFs here. Do not use fake certificate artwork.

After adding a file, update the matching certificate in `src/data/portfolio.ts`:

```ts
file: "assets/certificates/ef-set-english-c2.pdf",
status: "verified"
```

Recommended filenames:

```text
ef-set-english-c2.pdf
mongodb-nodejs-developer.pdf
huawei-overview-of-ai.pdf
introduction-to-prompt-engineering.pdf
ccna1.pdf
python-online-diploma.pdf
iot-online-certification.pdf
tensorflow-certificate.pdf
```
